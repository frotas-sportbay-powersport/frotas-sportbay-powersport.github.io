# Gestão de Logística de Frota — Sportbay Powersports

Painel de logística de frota (BRP): agenda semanal de tração e apoios, nova reserva, fila de aprovação, checklist de saída/retorno, cadastro de usuários, frota e permissões por perfil (Gerente, Aprovador, Motorista, Solicitante).

## Como usar
Acesse https://frota.fluxodesksportbay.com.br ou abra `index.html` no navegador. É um único arquivo HTML, sem dependências.

> Os dados ficam salvos no navegador de cada usuário (localStorage). Use "Restaurar dados de exemplo" para voltar ao estado inicial.
